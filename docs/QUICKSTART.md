# Lilt 快速上手

[返回首页](../README.md) · [下载最新版](https://github.com/limyum-creator/lilt-releases/releases/latest)

适用于 Apple Silicon（M1 及更新芯片）、macOS 14+。当前测试版为 **0.5.23 / build 37**。

## 安装与打开

1. 在 Release 下载 `.dmg`。GitHub 自动生成的 “Source code” 不是安装包。
2. 升级时先退出旧版，把 Lilt 拖进「应用程序」，复制完成后推出磁盘映像。
3. 从「应用程序」打开 Lilt。首次启动会打开工作台引导，提示卡跟随当前功能入口。

当前是本机开发签名的测试包，尚未经过 Apple 公证。如首次打开被拦截，确认来源后，在「系统设置 → 隐私与安全性」中允许打开。[Apple 官方说明](https://support.apple.com/zh-cn/102445)

点击菜单栏图标，或按 **Control + Option + 空格** 展开灵动岛。**Control + Option + A** 可以呼出岛内助手；若快捷键被其他软件占用，直接点击岛内最左侧猫标。

工作台顶部「Lilt 助手」旁边的对话气泡是对话入口。素材库和完整工具参数在工作台，常用快捷操作也能在岛内完成。

## 先做一条完整工作流

### 下载一条视频

复制支持的平台分享链接，等待岛内提示，或在工作台「链接下载」里粘贴。可按需要保存标题文案、开启下载后转录或自动处理。

需要登录的平台先在自己的电脑登录；有些作品的权限或平台变化会影响下载。出现频繁访问暂停时，保留队列、等待冷却，再按提示手动继续，不要连续重试。

### 把口播变成文字

进入「视频转录」，拖入视频或音频。第一次先到 **设置 → 语音模型** 下载合适的模型：按速度、精度和所需语言选择。

识别在本机完成，支持中英日等多种语言，输出 TXT 文稿与 SRT 字幕。运行组件已包含，语音模型不随 DMG 打包。长视频可在后台处理。

### 把原文交给 Lilt

在转录结果选择 **接着处理 → 提炼要点**，也可以选择改写、口播稿、标题话题或翻译。

对话会准备好提示词和附件。先检查来源，点击「查看原文」查看完整内容，再修改要求并发送。下载文案的改写会携带相应标题正文；组图交接会携带整组图片路径。

交接本身不发起收费请求。主动开启的转录后自动整理按保存的设置执行。

## 截图、贴图与文字

- `⌃⌥S`：选区截图，选区后可复制、保存、贴图、识字或交给 Lilt。
- `⌃⌥C`：选区后直接复制，可按设置套用圆角、阴影与描边。
- `⌃⌥O`：在本机离线提取截图文字并复制。
- `⌃⌥T`：识别截图文字并翻译，使用已配置的聊天模型，按服务商规则计费。

四组快捷键均可在 **设置 → 快捷键** 中修改。截图权限按系统提示授予；桌面贴图可拖动、滚轮缩放，按住 `⌥` 滚轮调整透明度，双击可折叠。识字在本机完成，截图翻译需要先接入聊天服务。

## 接入自己的模型

### 对话与文字整理

打开 **Lilt 助手 → 模型设置**，或 **设置 → AI 模型**：

1. 展开服务商，确认接口地址与类型。OpenAI 官方连接使用 Responses，其他服务可选 OpenAI 兼容对话或 Anthropic Messages。
2. 保存自己的 API Key；无认证的本地服务关闭「需要密钥」即可，不必填写假密钥。
3. 点击「读取全部模型」，在「供应商列表」中勾选常用模型，可多选、全选或全不选，并可切换到「仅已选」检查。勾选会自动保存，只有这些模型会出现在聊天选择器中；刷新目录保留勾选，新返回的模型不会自动加入。也可手填模型名或接入点 ID，「添加并使用」会同时勾选并切换到它。
4. 在聊天选择器中切换本次要使用的模型。设置中的「测试对话」会测试该连接当前已选的模型；若当前使用其他连接，则测试本连接勾选清单中的第一项。列表读取成功说明服务可达，对话测试才能检查模型能否回答。

岛内与工作台共用可搜索的模型选择器。勾选显示与切换当前模型各自独立；取消勾选当前模型后，需要重新选择再发送。升级已有连接时保留当前模型和手填别名，完整目录仍可随时勾选。OpenAI Responses 可按模型支持选择思考强度与回答长度；其余默认沿用服务商参数。纯文字模型可关闭「允许 Lilt 工具调用」，仍可聊天、翻译与整理文案。

DeepSeek、通义千问、OpenRouter、Claude 和兼容接口可以按相应格式接入。本机与局域网模型不限定 Ollama；Strata、LM Studio、llama.cpp、vLLM 等只要提供支持的 HTTP 接口，都可以添加为独立连接。

聊天输入区旁的「思考」菜单可切换所选模型支持的思考程度；不支持的模型或接口使用其默认行为。顶部显示当前对话名，点击「上下文占用」可查看估算 token、已知模型窗口及累计输入 / 输出用量。本地与未知型号没有可靠上限时只显示估算 token，不显示百分比。

显示「未接入」的服务商尚未完成配置；其预设名称只是候选，默认不勾选。Claude 预设来自 Lilt 内置列表，接入需在 Lilt 中主动配置，不自动读取本机 Claude 客户端配置。

### 管理对话与空间

侧栏对话右侧的「…」或右键菜单支持重命名、归档和删除。归档会隐藏侧栏条目，消息与草稿保留；可到 **设置 → 对话与存储 → 管理对话与归档** 恢复。

管理窗口支持搜索、多选和永久删除。设置中的「彻底删除所有对话」会在确认后删除活动及已归档记录、上下文缓存和旧版对话备份，无法恢复；下载素材、生成结果与模型密钥会保留。正在处理的当前对话需要先停止才能归档或删除。

### 连接本机与其他电脑的模型

「添加云端或本地连接」先选择运行位置：这台电脑、其他电脑 / 服务器、云端服务。Strata、LM Studio、Ollama、llama.cpp、vLLM 提供常用设置模板，也可连接其他兼容服务。模板的端口只是常见默认值，请以实际服务提供的地址为准。连接可以改名或移除，密钥可单独清除；多账号也可以分别保存。

以另一台电脑上的 Strata 为例：

1. 在 WorkPC 的 Strata 中启动要使用的模型，并确认 API 服务已启动。先启动 Qwen 或 Gemma 中的一个即可。
2. 在 Lilt 的 AI 模型设置展开「本机 / 局域网模型」，或选择「添加云端或本地连接」，为不同服务分别命名。
3. 填入可从 Mac 访问的地址，例如 `http://WorkPC-IP:8080/v1`。使用实际监听端口；Strata 默认仅监听自己时，可以使用已配置的 SSH 端口转发，并在 Lilt 填写转发后的本机地址。
4. 选择「OpenAI 兼容对话」，按服务设置决定是否需要密钥。点击「读取全部模型」，使用服务器返回的完整 ID，接着「测试对话」。

`localhost` 和 `127.0.0.1` 永远指正在运行 Lilt 的这台 Mac。直接连接 WorkPC 时使用它的局域网 IP、主机名或已连通的 Tailscale 地址；如果使用 SSH 转发，Mac 上的 `127.0.0.1` 才是正确地址。模型在同一服务内切换时刷新目录即可；不同端口的服务可分别保存连接。

超时、找不到主机、连接拒绝、认证失败、模型不存在与不支持工具会给出不同提示。启动模型只解决模型加载，还需确认 API 已启动、地址可达。Strata 的 Qwen / Gemma 用于对话，生图需要另接图片服务。

ChatGPT、Claude 等网站或桌面订阅不一定包含开发者 API 额度；请按对应服务商的说明准备。第三方模型服务的可用功能和计费由其提供方决定。

### 生图与参考图改图

在 **设置 → 生图模型** 单独配置接口和模型。可读取并搜索模型列表，也可手填。OpenAI 可以复用已配置的 OpenAI 对话密钥，自定义连接也可用于图片服务并复用认证；图片权限与可用额度由对应服务和项目决定。切换图片服务后，各服务已有的地址、模型、认证及质量设置会保留。

本机 / WorkPC 图片服务需提供 OpenAI Images 兼容接口；选择「本机 / WorkPC 图片接口」并按需关闭认证。ComfyUI 原生工作流接口与 Images 协议不同，不能把它的网页地址直接当作 Images 接口使用。

在图片工具选择生图，或把图片结果「接着处理」交给 Lilt。要拼图、扩图，使用本地工具即可；要调用生成服务，先确认接口支持相应生成或参考图能力。

素材库右键可直接「发送到 AI 聊天」或「发送到 AI 生图」，组图与多选素材会携带完整图片清单。生图页分别设置参考图用法、输出数量、尺寸和质量：「整组共同参考」将全部参考图用于同一组结果，「逐张改图」分别处理每张原图。要保留所有原图做长图或宫格，选择本地拼图排版。海报与封面预设则让生图模型结合全部选图，自行设计拼接、主辅图和标题，并自动切换为整组共同参考。

生图、改图、扩图与拼图会记录进度和全部结果，可从图片工具或「任务记录」查看；生成结果也进入素材库。点击聊天缩略图或本机图片链接可在 Lilt 内预览、切换组图。清除任务记录保留素材，取消或失败时已保存的结果也会保留。

本地扩图可一次加入多张图片，在「预览图片」切换查看后保存全部。带参数记录的图片任务可点击「重新设置」恢复输入和选项，确认后再执行。预览窗口支持左右方向键切换、⌘W 或 Esc 关闭；素材库导出清单和经确认的废纸篓操作也包含 AI 与本地图片结果。

### 长文、停止和继续

Lilt 可以分页读取长文、复用后台任务，并在整理旧过程后保留可读回的记录。阶段暂停时可以在原对话选择「继续此任务」，不需要重新准备素材。

停止会取消当前模型请求与等待，不再自动发送下一轮。已提交的下载、转录或转换任务留在任务记录，需在那里单独取消或重试。

请求、工具和用量边界能减少空转，不能保证零费用，也不能撤销服务商已经产生的用量。请先以短文本和少量素材试用。

## MCP 连接

支持本地 MCP 的客户端，可以使用 Lilt 提供的素材处理能力。

到工作台 **设置 → MCP**，复制界面提供的当前连接配置，再按所用客户端的方式添加。随包提供所需运行组件，不必另外安装 Node.js 或 Python。

不同客户端对本地文件、工具授权和配置位置的处理不同。只在需要的范围授权；不要把密钥或私人配置发到 Issues。若用工具资源管理器统一维护连接，以其资源库和分发规则为准。

## 数据、隐私与更新

- 本机数据：`~/Library/Application Support/MaterialIsland`。
- 新安装默认输出：`~/Downloads/Lilt`；升级沿用已有目录。
- 本地转录、裁切调色、拼图、扩图与格式处理在本机完成。
- 云端 AI 会接收你发送的相应内容、必要上下文或生图参考，请按自己的素材隐私要求选择服务。
- API Key 保存在本机；不要放入对话素材或公开反馈。
- 工具不提供删除或终端执行；脚本可以生成并另存，不代为运行。重要文件仍建议自行备份。

0.5.0 及以上版本可在 **设置 → 软件更新** 检查更新。更新包校验摘要和发布签名后安装；这与 App 的 Apple 公证是不同机制。

当前聊天不直接理解图片或视频画面。视频通过口播转录读取；图片可以交给本地工具或作为生图参考。模型输出应按实际使用需求检查。

## 遇到问题

先检查版本、相应配置和任务记录。平台登录、访问频率限制、API 额度与模型权限需要分别处理。

[提交反馈](https://github.com/limyum-creator/lilt-releases/issues/new/choose)时请附：Lilt 版本、Mac 芯片、macOS、复现步骤、预期与实际结果。模型问题注明服务商、模型名和脱敏错误。

截图或录屏前遮住私密资料。不要上传 API Key、Cookie、密码、音乐密钥或整个数据目录。
