# Lilt 快速上手

[返回首页](../README.md) · [下载最新版](https://github.com/limyum-creator/lilt-releases/releases/latest)

适用于 Apple Silicon（M1 及更新芯片）、macOS 14+。当前测试版为 **0.5.11 / build 25**。

## 安装与打开

1. 在 Release 下载 `.dmg`。GitHub 自动生成的 “Source code” 不是安装包。
2. 升级时先退出旧版，把 Lilt 拖进「应用程序」，复制完成后推出磁盘映像。
3. 从「应用程序」打开 Lilt。首次启动会打开工作台引导，提示卡跟随当前功能入口。

当前是本机开发签名的测试包，尚未经过 Apple 公证。如首次打开被拦截，确认来源后，在「系统设置 → 隐私与安全性」中允许打开。[Apple 官方说明](https://support.apple.com/zh-cn/102445)

点击菜单栏图标，或按 **Control + Option + 空格** 展开灵动岛。**Control + Option + A** 可以呼出岛内助手；若快捷键被其他软件占用，直接点击岛内最左侧猫标。

工作台顶部「Lilt 助手」旁边的对话气泡是对话入口。素材库和完整工具参数在工作台，常用快捷操作也能在岛内完成。

## 先做一条完整工作流

### 下载一条视频

复制支持的平台分享链接，等待岛内提示，或在工作台「链接下载」里粘贴。可按需要保存标题文案、开启下载后转录或自动处理。

需要登录的平台先在自己的电脑登录；有些作品的权限或平台变化会影响下载。出现频繁访问暂停时，保留队列、等待冷却，再按提示手动继续，不要连续重试。

### 把口播变成文字

进入「视频转录」，拖入视频或音频。第一次先到 **设置 → 语音模型** 下载合适的模型：按速度、精度和所需语言选择。

识别在本机完成，支持中英日等多种语言，输出 TXT 文稿与 SRT 字幕。运行组件已包含，语音模型不随 DMG 打包。长视频可在后台处理。

### 把原文交给 Lilt

在转录结果选择 **接着处理 → 提炼要点**，也可以选择改写、口播稿、标题话题或翻译。

对话会准备好提示词和附件。先检查来源，点击「查看原文」查看完整内容，再修改要求并发送。下载文案的改写会携带相应标题正文；组图交接会携带整组图片路径。

交接本身不发起收费请求。主动开启的转录后自动整理按保存的设置执行。

## 接入自己的模型

### 对话与文字整理

打开 **Lilt 助手 → 模型设置**，或 **设置 → AI 模型**：

1. 选择服务商。
2. 填入自己的 API Key，保存并使用。
3. 在下拉菜单里选择模型；需要时刷新列表或手填服务商提供的模型名。
4. 先发一条短文本，确认连接、工具能力和服务商用量。

DeepSeek、通义千问、OpenRouter、Claude 和兼容接口可以按相应格式接入。本机 Ollama 需先运行服务并准备模型。自定义接口需要确认地址、模型名及 OpenAI 兼容 / Anthropic 格式。

ChatGPT、Claude 等网站或桌面订阅不一定包含开发者 API 额度；请按对应服务商的说明准备。第三方模型服务的可用功能和计费由其提供方决定。

### 生图与参考图改图

在 **设置 → 生图模型** 单独配置接口和模型。聊天 Key 不一定具有生图权限。

在图片工具选择生图，或把图片结果「接着处理」交给 Lilt。要拼图、扩图，使用本地工具即可；要调用生成服务，先确认接口支持相应生成或参考图能力。

### 长文、停止和继续

Lilt 可以分页读取长文、复用后台任务，并在整理旧过程后保留可读回的记录。阶段暂停时可以在原对话选择「继续此任务」，不需要重新准备素材。

停止会取消当前模型请求与等待，不再自动发送下一轮。已提交的下载、转录或转换任务留在任务记录，需在那里单独取消或重试。

请求、工具和用量边界能减少空转，不能保证零费用，也不能撤销服务商已经产生的用量。请先以短文本和少量素材试用。

## 其他常用工具

| 功能 | 使用方式 |
| --- | --- |
| 视频剪辑 | 导入后预览，拖动时间轴两端选择保留片段，再导出 |
| 音视频处理 | 按导入类型选择处理视频、转换或提取音频等操作 |
| 图片裁切与调色 | 直接编辑，另存结果 |
| 扩图 | 选择比例，以纯色或模糊原图填充，调整相应参数 |
| 拼图 | 导入多张图片，选择长图或宫格；调整顺序和参数 |
| 素材库 | 空格预览、⌘ / ⇧ 多选、筛选、复制文案、拖到其他软件 |
| 快捷启动 | 在设置里加入常用应用，调整岛内工具顺序 |
| 音乐解锁 | 用于自己的已购买或下载文件，按格式要求准备密钥 |

每项结果可从「接着处理」继续交给下一个功能。外观、常用开关和完整输出目录可以在设置里调整。

## MCP 连接

支持本地 MCP 的客户端，可以使用 Lilt 提供的素材处理能力。

到工作台 **设置 → MCP**，复制界面提供的当前连接配置，再按所用客户端的方式添加。随包提供所需运行组件，不必另外安装 Node.js 或 Python。

不同客户端对本地文件、工具授权和配置位置的处理不同。只在需要的范围授权；不要把密钥或私人配置发到 Issues。若用工具资源管理器统一维护连接，以其资源库和分发规则为准。

## 数据、隐私与更新

- 本机数据：`~/Library/Application Support/MaterialIsland`。
- 新安装默认输出：`~/Downloads/Lilt`；升级沿用已有目录。
- 本地转录、裁切调色、拼图、扩图与格式处理在本机完成。
- 云端 AI 会接收你发送的相应内容、必要上下文或生图参考，请按自己的素材隐私要求选择服务。
- API Key 保存在本机；不要放入对话素材或公开反馈。
- 工具不提供删除或终端执行；脚本可以生成并另存，不代为运行。重要文件仍建议自行备份。

0.5.0 及以上版本可在 **设置 → 软件更新** 检查更新。更新包校验摘要和发布签名后安装；这与 App 的 Apple 公证是不同机制。

当前聊天不直接理解图片或视频画面。视频通过口播转录读取；图片可以交给本地工具或作为生图参考。模型输出应按实际使用需求检查。

## 遇到问题

先检查版本、相应配置和任务记录。平台登录、访问频率限制、API 额度与模型权限需要分别处理。

[提交反馈](https://github.com/limyum-creator/lilt-releases/issues/new/choose)时请附：Lilt 版本、Mac 芯片、macOS、复现步骤、预期与实际结果。模型问题注明服务商、模型名和脱敏错误。

截图或录屏前遮住私密资料。不要上传 API Key、Cookie、密码、音乐密钥或整个数据目录。
