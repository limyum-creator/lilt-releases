## 尚需实际环境反馈

- 不同服务商、模型和项目的权限、生成质量、工具兼容性与计费。

- 从 GitHub 到其他用户电脑的完整自动更新体验。
- 用户生成脚本的执行正确性；Lilt 工具不会代为执行脚本。

应用使用本机开发签名，尚未经过 Apple 公证。首次打开可能需要在系统隐私与安全设置中确认。

自动更新另使用发布签名和摘要校验，用于验证更新来源与内容，不等于 Apple Developer ID 签名或公证。
