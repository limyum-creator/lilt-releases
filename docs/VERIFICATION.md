# Lilt 0.5.11 验证范围

本页对应 **0.5.11 / build 25**，Apple Silicon、macOS 14+。记录验证范围，便于试用时区分已检查的行为和需要真实环境反馈的部分。

## 已完成

| 范围 | 结果 |
| --- | --- |
| Agent 执行边界、长任务与上下文恢复 | 31 / 31 |
| 素材、文案、转录与结果交接 | 25 / 25 |
| 实际轮廓动画：中间帧、过冲、跳变、窗口稳定性 | 16 / 16 |
| 七步跟随引导及窗口边界 | 18 / 18 |
| 指定窗口与输入框尺寸案例 | 5 / 5 |
| 合计 | **95 / 95** |

这些是定向离线检查，使用脚本化模型回复驱动实际执行循环，不向收费服务发请求。本轮未重跑完整全量矩阵。

安装到 `/Applications/Lilt.app` 后核对版本、文件复制、可执行文件摘要、deep-strict 签名，并确认正式进程启动和原生窗口显示。

DMG 另完成磁盘校验、只读挂载、应用内文件与符号链接逐项比对、签名、MCP 入口和处理运行组件 Dock 策略检查。当前 MCP 仍保留兼容的 `material_*` 工具 ID。

## 尚需实际环境反馈

- 真实收费模型的生成质量、各服务商和推理模型的高级协议差异。
- 其他 Mac、系统版本和显示器环境下的使用体验。
- 平台登录、平台变化及真实下载的兼容性。
- 从 GitHub 到其他用户电脑的完整自动更新体验。
- 用户导出脚本的执行正确性；Lilt 工具不会代为执行脚本。

当前聊天中的图片 / 视频画面理解尚未实现，不能把文件路径交接或口播转录理解为已经“看过”画面。图片处理和参考图生图是独立能力。

## 签名与公证

App 当前使用本机开发签名，尚未经过 Apple 公证。首次打开可能需要在系统隐私与安全设置中确认。

自动更新另使用发布签名和摘要校验。这验证更新来源与内容，不等于 Apple Developer ID 签名或公证。

首页截图来自当前原生界面，素材、对话和模型配置为演示用途，没有调用收费模型。它们展示交接与界面布局，不作为真实模型质量评测。
