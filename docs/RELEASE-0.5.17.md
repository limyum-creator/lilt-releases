# Lilt 0.5.17

**0.5.17 / build 31** 修复对话输入焦点与模型控件，补齐思考程度、上下文占用和对话管理。适用于 **Apple Silicon、macOS 14+**。

## 更新内容

- **连续输入保持焦点**：修复岛内输入每个字后失去焦点的问题，中文输入法上屏后可以继续键入；岛内和工作台使用同一套修正。
- **模型与思考选项更顺手**：模型选择按钮恢复左侧对齐，聊天输入区可直接选择当前模型支持的思考程度。设置中的思考选项同步补齐并使用中文名称。
- **查看当前上下文**：顶部增加上下文指示，点击可查看估算 token、已知模型窗口和累计用量。当前上下文与累计消耗分开显示；本地或未知模型缺少可靠容量时只显示估算 token 数。
- **对话名称与管理**：顶栏显示当前对话名，侧栏「…」和右键菜单支持重命名、归档及确认后删除。归档会隐藏侧栏条目，消息、草稿和附件继续保留。
- **管理归档与空间**：在「设置 → 对话与存储」搜索对话、恢复归档、多选永久删除或彻底清理全部记录及相关缓存。清理会保留下载素材、生成结果和模型密钥。

## 下载与安装

下载 **Lilt-0.5.17-macOS-arm64.dmg**，退出旧版后把 Lilt 拖入「应用程序」。0.5.0 及以上版本也可在「设置 → 软件更新」检查更新。已有数据、模型连接和输出目录继续沿用。

同页提供 `SHA256SUMS.txt` 校验清单；ZIP 和 `appcast.json` 供应用内自动更新使用。GitHub 自动生成的 “Source code” 是发行仓库文档快照，安装应用请选择 `.dmg`。

应用使用本机开发签名，尚未经过 Apple 公证。首次打开若被系统拦截，确认来源后在「系统设置 → 隐私与安全性」中允许打开。[Apple 官方说明](https://support.apple.com/zh-cn/102445)
