# Lilt 0.5.23

**0.5.23 / build 37** 新增面向单条视频与选题的「创作项目」工作区，完善多图生图工作流、对话图片预览去重、Agent 重复调用防护与 MCP 连接稳定性。适用于 **Apple Silicon、macOS 14+**。

## 更新内容

- **创作项目与选题工作区**：将「项目」升级为按单条视频或选题组织的独立创作空间（同时保留旧版 `.json` 项目快照导入导出兼容）。新建项目自动在 `~/Downloads/Lilt/项目/<项目名>` 下创建 `参考素材`、`AI 生图`、`AI 文稿` 目录；激活项目期间，新下载的对标视频与图文笔记、本地导入素材、口播转录稿、AI 生成图片与保存的文稿会自动归入当前项目并同步到项目文件夹。
- **项目专属 AI 工作区与素材库筛选**：每个项目配有独立的「选题备忘录」与专属 AI 对话列表，与 Lilt 助手交流时自动注入当前项目背景与已归集的对标素材，检索与保存文稿默认围绕当前项目进行。工作台顶栏、AI 助手与灵动岛均提供常驻项目切换胶囊；素材库支持按项目或「未归类素材」筛选，支持右键与多选批量归类。免费版最多可创建 5 个项目，解锁 Pro 后不限项目数量。
- **多图生图、图片任务与内置预览**：生图接口支持发送完整参考图（整组共同参考或逐张改图），海报与封面预设可结合全部选图设计构图；新增常用横竖比例、2K / 4K 与自定义尺寸。生图、改图、扩图与拼图均具备持久化任务记录；聊天中的图片结果同一轮自动去重、只展示一次预览，支持方向键切换与快捷键关闭。
- **Agent 执行去重与交接加固**：按实际输入、参数与参考图识别重复写入，中断或继续任务时复用已完成结果，避免重复计费调用；整组附件与多媒体转录交接保持完整。
- **MCP 与后台稳定性提升**：统一 macOS 符号链接目录（`/tmp`、`/var/folders`）下的 MCP Socket 物理路径哈希，进程收到 `SIGTERM` / `SIGINT` 退出时自动清理残留 `.sock` 文件；优化流式输出期间的主线程磁盘检查，校验「存为文稿」写入结果。

## 下载与安装

下载 **Lilt-0.5.23-macOS-arm64.dmg**，退出旧版后把 Lilt 拖入「应用程序」。0.5.0 及以上版本也可在「设置 → 软件更新」检查更新。已有数据、模型连接和输出目录继续沿用。

同页提供 `SHA256SUMS.txt` 校验清单；ZIP 和 `appcast.json` 供应用内自动更新使用。GitHub 自动生成的 “Source code” 是发行仓库文档快照，安装应用请选择 `.dmg`。

应用使用本机开发签名，尚未经过 Apple 公证。首次打开若被系统拦截，确认来源后在「系统设置 → 隐私与安全性」中允许打开。[Apple 官方说明](https://support.apple.com/zh-cn/102445)
